# Arquantix Tokenized Real Estate Vaults

Arquantix brings institutional-grade real estate investment on-chain through Base-native vaults. This repository contains the smart contract foundation for Arquantix tokenized real estate shares, stablecoin vaults, and participation tokens.

> Forked from [Ledgity Yield v2](https://github.com/LedgityLabs/ledgity-v2-contracts), original authors: [LedgityLabs](https://github.com/LedgityLabs).

---

## Investor Guide

Arquantix vaults let investors access real estate-backed vault shares with stablecoin deposits on Base. Your capital is deployed into a real estate project managed by Arquantix, and yield accrues automatically, reflected in the growing price of your vault share.

Each vault displays its target APR upfront, generated by the underlying real estate operation. Withdrawals are subject to a liquidity reserve; an exit fee or notice period may apply and is disclosed before you deposit.

Vaults are globally accessible after a simplified KYC process. Capital is at risk. Every vault is backed by a tangible asset with full on-chain transparency, but this does not constitute a guarantee.

## Quick Start

### Prerequisites

- Node.js 18+
- npm or yarn
- Foundry (for testing)
- Hardhat (for deployment)

### Installation & Setup

```bash
git clone <repo-url>
cd arquantix-contracts
npm install
npm run compile
```

### Available Scripts

| Command                    | Description                               |
| -------------------------- | ----------------------------------------- |
| `npm run compile`          | Compile smart contracts and generate ABIs |
| `npm run test`             | Run Foundry tests (protocol-v2)           |
| `npm run test:all`         | Run full test suite                       |
| `npm run size`             | Check contract sizes                      |
| `npm run deploy:base`      | Deploy contracts to Base                  |
| `npm run deploy-fork:base` | Deploy against a Base fork locally        |
| `npm run verify:base`      | Verify contracts on Basescan              |
| `npm run slither:report`   | Generate Slither security analysis report |
| `npm run prettier:check`   | Check code formatting                     |
| `npm run prettier:write`   | Format code with Prettier                 |

## Architecture

The Arquantix vault framework is built with modular smart contracts and security-first design principles, inheriting from the Ledgity Yield v2 codebase.

### Development Stack

- **Solidity 0.8.18**: smart contract language
- **Hardhat**: compilation, deployment, and tasks
- **Foundry**: fast, portable testing framework
- **TypeScript**: type-safe deployment scripts
- **OpenZeppelin 4.9**: battle-tested contract libraries

### Protocol Design

- **ERC-4626 vaults**: standard-compliant yield-bearing vault shares
- **Modular architecture**: isolated components for vault logic, liquidity, and access control
- **Upgradeable patterns**: proxy-based contracts for future improvements
- **Base network**: stablecoin deposits
- **On-chain transparency**: auditable yield and liquidity state

### Core Contracts

| Contract                   | Description                                  |
| -------------------------- | -------------------------------------------- |
| `LedgityYieldVault.sol`    | ERC-4626 vault: deposits, withdrawals, yield |
| `GlobalAccessList.sol`     | Role-based access control                    |
| `VaultLiquidityModule.sol` | APR calculations and fee management          |
| `CCIPTokenModule.sol`      | Cross-chain token transfers (Chainlink CCIP) |

## Testing

```bash
# Run protocol-v2 tests
npm run test

# Run all tests
npm run test:all

# Target a specific contract
forge test --match-contract VaultComputations

# With gas report
forge test --gas-report

# With traces
forge test -vvv

# Fuzz with more runs
forge test --fuzz-runs 10000
```

**Test configuration:** 250 fuzz/invariant runs by default, 10,000 in CI.

## Deployment

### Environment Setup

Create a `.env` file:

```bash
DEPLOYER_PK=your_private_key_here

BASE_RPC_URL=https://mainnet.base.org
BASE_VERIFY_API_KEY=your_basescan_api_key
```

### Deploy to Base

```bash
# Test against a local fork first
npm run deploy-fork:base

# Deploy to mainnet
npm run deploy:base

# Verify on Basescan
npm run verify:base
```

### Post-Deployment

1. Run `npm run typings` to regenerate TypeScript types
2. Update deployment addresses in `data/deployments.json`
3. Run `npm run slither:report` for a fresh security scan
